# Next.js 16.4.3 facts (verified in node_modules/next/dist/docs/01-app)

- middleware.ts is DEPRECATED → use root `proxy.ts` exporting `proxy` (03-api-reference/03-file-conventions/proxy.md). Node runtime only. Proxy = optimistic cookie check/redirect only; never the sole authorization (02-guides/authentication.md ~1033, 1121).
- Real authz: server-only Data Access Layer, `verifySession()` wrapped in React `cache()`, re-checked inside EVERY Server Action and Route Handler (Server Actions are public POST endpoints — 02-guides/data-security.md ~281-368). Don't gate auth in shared layouts.
- Async request APIs mandatory: `await cookies()`, `await headers()`, `await params`, `await searchParams`. Route ctx type: `RouteContext<'/x/[id]'>`.
- Caching: `cacheComponents: true` in next.config.ts; `'use cache'` + `cacheLife()` + `cacheTag()` from next/cache. `'use cache'` cannot read cookies/headers (pass as args or `'use cache: private'`).
- **Withdrawal ≤60s**: `revalidateTag(tag,'max')` serves stale up to a year — DO NOT use for withdrawal. Use `updateTag(tag)` inside the withdraw Server Action (immediate), or `revalidateTag(tag, { expire: 0 })` in route handlers. Also: never cache private/shared-learning payloads in a cross-user cache; apply visibility filter at query time. Multi-instance needs a cache handler that propagates tags.
- next/font/google Poppins with `variable: '--font-poppins'`; Tailwind v4 `@import 'tailwindcss'` + `@theme inline { --font-sans: var(--font-poppins); }`.
- Turbopack default; Node ≥20.9; route segment `dynamic`/`revalidate` configs removed under cacheComponents.
- GSAP: gsap@3.15.0 + @gsap/react@2.1.2 (peer react>=17 ✓), all plugins free (ScrollTrigger, SplitText). Use `useGSAP` in 'use client' components, `gsap.matchMedia()` for prefers-reduced-motion; portal area: minimal motion only.
