# Frontend & UX Architecture Summary (docs/plan/gemini-frontend-ux.md)

1. **Routes & Roles**: Public discovery (`/`, `/about`, `/products/*`, `/insights/*`, `/request-demo`), Auth (`/login`, `/invite/[token]`, `/workspace/select`), Client Portal (`/portal/client/*`: observations, entitled demos, shared learning, themes, admin), Employee Portal (`/portal/employee/*`: playground, live broadcasts, experiments, knowledge), Moderator Console (`/portal/moderator/*`: queue, review diff/redact workbench, reports, audit), Product Owner (`/portal/product-owner/*`: themes, improvement ideas), Portal Admin (`/portal/admin/*`).
2. **Layouts**: Public marketing shell with announcement bar, sticky header with mega-menus, right floating demo tab, cookie banner, multi-column navy footer. Authenticated portal shell with active tenant switcher, role-scoped sidebar, and in-app notification outbox bell.
3. **Components & Azentio Design System**: Signature 3px mint underline (`.span-border-bottom`), 5-column product row, animated stats band, card carousels, HubSpot-style contact block, lifecycle status badges (`draft`, `submitted`, `in_review`, `approved`, `published`, `withdrawn`), structured contribution form with explicit sharing selector & independent consents (a–d), side-by-side moderation redaction workbench, theme dashboard with distinct org threshold check (min 3), and empty states.
4. **Tailwind CSS v4 & Fonts**: Theme tokens declared in `app/globals.css` with `@theme` directive (`--color-az-navy: #16303d`, `--color-az-mint: #55ffbe`, `--color-az-green: #2ed88e`, `--color-az-mint-tint: #ddfff2`, `--radius-card: 12px`, `--radius-pill: 50px`). Next.js `next/font/google` Poppins integration.
5. **GSAP Animation**: `@gsap/react` `useGSAP` in client component boundaries, hardware-accelerated transforms & opacity only, auto-reverting cleanup on unmount, `gsap.matchMedia()` for `prefers-reduced-motion: reduce`.
6. **'Seasonality Context' Demo Walkthrough**: 8-step click path from Client A, B, and C submissions, through Moderator redaction/publishing, Theme emergence with 3 distinct orgs, PO improvement idea creation, Client loop closure, to Client A withdrawal triggering real-time <=60s search/AIRA purge and automatic Theme suppression due to org count falling below 3.
