# Decision: Frontend Architecture, Design Tokens & GSAP Motion Standard

- Decision ID: decision-1793358448190-529902a9
- Recorded by: cross-agent-mcp-bridge
- Recorded: 2026-10-30T11:07:28.190Z

Frontend & UX Architecture:
1. Design System: Standard Tailwind v4 `@theme` tokens in `app/globals.css` with Azentio brand palette (#16303D navy, #55FFBE mint, #2ED88E green, #DDFFF2 mint-tint), Poppins loaded via `next/font/google`, 12px card radii, and 50px pill buttons.
2. Motion: GSAP 3.12+ with `@gsap/react` `useGSAP` in client components, hardware-accelerated transforms/opacity only, automated cleanup via scope, and strict `prefers-reduced-motion` compliance via `gsap.matchMedia()`.
3. Route & Shell Architecture: Separation between public marketing route group `(public)` with full header/footer and authenticated portal shell `portal/` with active workspace switcher, role-based sidebar, and server-side RBAC.
4. Next.js 16.4.3 Alignment: Async Request APIs (`await params`, `await searchParams`), `proxy.ts` for network boundary routing, and Server Actions `updateTag()` / `refresh()` for immediate read-your-writes and tenant switching.
