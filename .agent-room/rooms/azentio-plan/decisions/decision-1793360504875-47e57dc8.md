# Decision: AIRA and embeddings: Cohere via OpenAI-compatible API (user-confirmed)

- Decision ID: decision-1793360504875-47e57dc8
- Recorded by: cross-agent-mcp-bridge
- Recorded: 2026-10-30T11:41:44.875Z

This replaces the earlier Transformers.js embeddings choice.

- Use the `openai` SDK with `baseURL` set to `https://api.cohere.ai/compatibility/v1`. Configure it with the env vars `AI_API_KEY`, `AI_MODEL` (chat, e.g. `command-a-plus-05-2026`) and `EMBED_MODEL` (e.g. `embed-v5.0-pro`). The provider can be swapped through env alone.
- Supported endpoints are `/chat/completions` and `/embeddings`. `/embeddings` accepts `encoding_format` of float or base64; the `dimensions` and `user` params are unsupported, so store the returned vector length in `shared_copy_embeddings.dims`.
- Chat does not support Cohere-native `documents`, `citation_options` or `connectors`, nor `n`, `logit_bias` or `parallel_tool_calls`. AIRA therefore builds its own numbered context block from authorised shared copies and validates the cited IDs against that set before returning them.
- Only approved shared copies and public content are sent. Private drafts, source versions, reviewer notes and tenant IDs are never sent.
- Seed embeddings are cached as fixtures, so a demo still works under rate limits. `@huggingface/transformers` has been removed from the install list.
- Source: https://docs.cohere.com/docs/compatibility-api
