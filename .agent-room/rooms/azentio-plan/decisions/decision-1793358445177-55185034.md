User confirmed **@phosphor-icons/react** (MIT) as the single icon library. Rationale: azentio.com icons are thick rounded navy (#16303D) outlines with one solid green (#2ED88E) accent element; Phosphor weights match best.

Usage rules:
- Public category tiles / hero / empty states: `weight="duotone"` (navy via `currentColor`, secondary layer tinted green via CSS override — verify selector in app) or `weight="bold"`.
- Portal UI (nav, buttons, tables): `weight="regular"`, navy, 20/24px. One size scale; don't mix weights except selected vs not.
- Decorative icons next to labels get aria-hidden; icon-only buttons need aria-label + tooltip. No text glyphs (→ ✓ ×) as icons. No icon reused for two meanings.
